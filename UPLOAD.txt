ОБНОВЛЕНИЕ САЙТА НА GITHUB

Распакуйте архив и загрузите его содержимое в корень Liga-Korkem,
заменяя одноимённые файлы. Сохраните папки vendor и videos.
Сам ZIP загружать не нужно. Этот UPLOAD.txt можно не загружать.

Для загрузки видео с телефона нужны обновлённые файлы:
index.html
redesign.css
player-clips.js
video-upload.js
player-stories.js
profile-editor.js
vendor/tus-4.3.1.min.js
vendor/tus-LICENSE.txt

КАК АДМИНУ ДОБАВИТЬ ВИДЕО
1. Откройте сайт на телефоне.
2. Нажмите «Войти как админ» и введите прежний код 0722.
3. Под карточкой нужного игрока нажмите «＋ Добавить видео».
4. Выберите видео из галереи и напишите название момента.
5. Нажмите «Загрузить видео» и дождитесь сообщения «Готово!».

Email и аккаунт не нужны. Код проверяется сервером.
Видео хранится в Supabase и доступно всем посетителям.
Хранилище и сервер уже настроены в проекте KorkemLiga.
Дополнительно выполнять SQL или менять настройки Supabase не требуется.

Форматы: MP4, MOV, WebM. Максимальный размер: 50 МБ.
Для совместимости с разными телефонами используйте MP4 с кодеком H.264.
Во время загрузки не закрывайте страницу. При ошибке можно повторить отправку.
Если прошло 30 минут с момента входа, форма попросит подтвердить код ещё раз.

КАК РЕДАКТИРОВАТЬ ОПИСАНИЕ
1. Войдите как админ по коду 0722.
2. Под карточкой игрока нажмите «✎ Редактировать описание».
3. Измените игровой образ, заголовки и тексты разделов.
4. Если описание вымышленное, оставьте пометку «Придумано ИИ».
5. Нажмите «Сохранить описание» и дождитесь подтверждения.

Описание сохраняется в Supabase и отображается у всех посетителей.
Настройка хранилища описаний уже выполнена, дополнительный SQL не нужен.
